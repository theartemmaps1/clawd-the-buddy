## Install

1. Download **Clawd-Setup-*.exe** below and run it.
2. Windows may say "Windows protected your PC" because the installer isn't code-signed yet. Click **More info**, then **Run anyway**.
3. Follow the wizard. It asks where to install, whether Clawd should start with Windows, and whether to connect him to Claude Code.

## Already installed?

Run the new installer again and it offers **Repair**, **Update** or **Uninstall**. Installed copies also check for updates by themselves (tray menu: Check for updates).

To remove him: Windows Settings, Apps, Clawd. The uninstaller can disconnect him from Claude Code and, if you want, forget his memories.

To check the download, compare its SHA-256 with `SHA256SUMS.txt`.
